PLAT IPTV - Privacy Policy

Last updated: October 30, 2026

1. About PLAT IPTV

PLAT IPTV is a media player application. It does not provide, host, sell, or distribute television channels, playlists, or media content. Users are responsible for obtaining their own lawful media sources and access credentials.

2. Personal Data

The app operator does not collect or receive users' IPTV login credentials. Users enter their own connection details directly into the application.

3. Local Storage

IPTV connection details are stored locally on the user's television to allow convenient access without entering them every time. These details are not uploaded to servers operated by PLAT IPTV.

4. Connections to IPTV Providers

The application communicates with the IPTV server selected by the user to authenticate access and retrieve available media. The selected IPTV provider may process connection information according to its own privacy practices.

5. Advertising and Analytics

PLAT IPTV does not include advertising, third-party analytics, or user-tracking services.

6. User Responsibility

Users are responsible for the playlists, services, and media sources they configure. PLAT IPTV does not supply subscriptions or grant access to copyrighted content.

7. Data Management

Users can remove locally stored application data using the data-management or application removal options available on their television.

8. Changes to This Policy

This policy may be updated if the application's features or data practices change. The latest version will be published on this page.
